# 001 — Walking skeleton: fixture → job directory → fake transcript, four loops green

## Type

AFK

## Parent PRD

`issues/prd.md`

## What to build

The thinnest end-to-end path that proves the package, the fixture, the job directory and the smoke loop all exist and agree. A synthetic six-second clip is generated by the test session, ingested into a job directory under the data dir, transcribed by the fake transcriber into a Transcript model, and the smoke command walks that same path and asserts the transcript. No planner, no render, no web page yet.

Covers PRD "Global contracts" (job directory, statuses), `config`, the Transcript part of `contracts`, `jobs`, the fake half of `transcriber`, `smoke`, and the fixture from "Testing Decisions". Decisions 2.2, 11.1 (status names and `job.log`), 12.1, 13.1.

Package skeleton: `src/shortsmith/{config,contracts,jobs,transcriber,smoke}.py`, `tests/conftest.py`, ruff and pyright configured in `pyproject.toml`. No new dependencies; `pydantic-settings` is already present for `config`.

## Acceptance criteria

- [ ] `tests/conftest.py` generates the 12.1 fixture once per session with ffmpeg into a temp dir: 6 s, 1080x1920, 30 fps, moving colour gradient, drawn face ellipse in the top third, audio with six tone bursts at known times; file < 1 MB; nothing under `tests/` is a video and `.gitignore` covers `*.mp4`.
- [ ] `config.Settings` loads every key in `.env.example` from the environment with matching defaults, plus `SHORTSMITH_DATA_DIR`; a test constructs it without a `.env` file.
- [ ] `contracts.Transcript` holds words with `text`, `start`, `end` and per-segment logprob flags; Pydantic with `extra="forbid"`.
- [ ] `jobs.create(data_dir, ...)` makes `jobs/<job_id>/{job.json, input/, work/, out/}` per 2.2; `jobs.transition(job, status)` writes `job.json` and appends a timestamped line to `job.log` on every transition; illegal transitions raise; `failed` carries `{step, message, detail}` per 11.1.
- [ ] `transcriber.Transcriber` is an interface; `FakeTranscriber` is co-located in the same module and returns twelve words aligned to the fixture's six bursts, deterministic.
- [ ] `python -m shortsmith.smoke` creates a job from the fixture, runs the fake transcriber, writes `work/asr.json`, moves the job `uploaded → transcribing → (next status placeholder)` and exits 0 with a one-line summary; exits non-zero with the failing assertion otherwise.
- [ ] `uv run ruff check .`, `uv run pyright`, `uv run pytest -q`, `uv run python -m shortsmith.smoke` all pass from a clean checkout.
- [ ] Tests: job directory layout, every status transition writes `job.json` and a log line, fixture face ellipse is in the top third (pixel probe via ffmpeg), FakeTranscriber word times sit on the burst times.
