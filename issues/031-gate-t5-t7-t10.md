# 031 — Technical gate T5, T7 and T10: caption coverage and lip-sync, luma and frozen frames, mid-word cuts

## Type

AFK

## Parent PRD

`issues/prd.md`

## What to build

Three signal-analysis checks in `qa.technical`, run in order after T4 and T6 and before T8. T5 samples three random timestamps and asserts a caption page covers each, then measures lip-sync lag by envelope cross-correlation of the voice stem against the cut clip's audio (0 ± 1 frame). T7 asserts mean luma ≥ 12/255 on every frame and no identical-frame run longer than 0.5 s before the finale, via signalstats and framehash. T10 asserts every `cut` boundary lies within 0.03 s of a word start or end.

Covers PRD `qa.technical` T5, T7, T10. Decisions 10.1, 3.1, 6.1.

## Acceptance criteria

- [ ] T5: three timestamps drawn from a seeded RNG recorded in `qa.json`; each is inside a caption page's window; lag measured by cross-correlation with numpy, reported in frames, fails outside ±1.
- [ ] T7: per-frame mean luma from signalstats, fail on any frame < 12/255 with the time; framehash runs of identical frames > 0.5 s fail with the span, excluding the finale.
- [ ] T10: cut boundaries from `work/cut.json` compared to the fixed word list; fail names the boundary and the nearest word.
- [ ] Each check has a passing and a failing synthetic input test (a page gap, a shifted voice stem, a black frame inserted, a frozen second, a cut 0.05 s inside a word).
- [ ] `qa.json` order is T1, T2, T3, T4, T5, T6, T7, (T8 placeholder), T9, T10, (T11–T13 placeholders); placeholders are recorded as `not_implemented` and do not pass silently: `delivered` requires every listed check to be `pass` once 032 lands, and until then the summary panel shows them grey.
- [ ] Smoke passes T5, T7 and T10 on the fixture.
